Papou HUD for **Minecraft 26.3**. Players with 1.4.0 or later get this update from the popup at startup.

## New: HUD size

The settings menu (`M`) has a new **HUD size** row: `-` makes the friend panels, compass and coordinates smaller, `+` makes them bigger, from 50% to 150% in steps of 10%. Only Papou HUD changes size; the rest of the game's interface stays as it is. The change shows right away and is saved with the other settings.

## Files

- `papouhud-1.4.3.jar`: the mod, for players (and for Fabric servers).
- `papouhud-paper-1.4.3.jar`: the plugin for Paper 26.3 servers. It doesn't go in `.minecraft/mods`.
