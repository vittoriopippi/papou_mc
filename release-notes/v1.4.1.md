Papou HUD for **Minecraft 26.3**. Players with 1.4.0 get this update from the popup at startup.

## Fixed: Inventory Sorter's "Category" order on Paper servers

With [Inventory Sorter](https://modrinth.com/mod/inventory-sorting) set to **Sort by: Category**, chests on a Paper server (or any server without Inventory Sorter) came out in alphabetical order. On those servers Inventory Sorter sorts from your own game, using the order of the creative inventory's tabs, and Minecraft fills those tabs only when you open the creative inventory, so in survival they were empty.

Papou HUD now fills them when you join a server, and "Sort by: Category" groups the items as in the creative inventory: logs and planks, stone, dirt, torches, redstone, weapons, food, materials. To switch Inventory Sorter to Category, hover over its sort button in a chest and scroll the mouse wheel.

Nothing changes in singleplayer or on Fabric servers with Inventory Sorter, where the server does the sorting.

## Files

- `papouhud-1.4.1.jar`: the mod, for players (and for Fabric servers).
- `papouhud-paper-1.4.1.jar`: the plugin for Paper 26.3 servers. It doesn't go in `.minecraft/mods`.
