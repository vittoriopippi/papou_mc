Papou HUD for **Minecraft 26.3**. Players with 1.4.0 or 1.4.1 get this update from the popup at startup.

## Fixed: the shortcuts on Minecraft 26.3

Since Minecraft 26.3 numbers the keyboard keys differently, the default shortcuts were on the wrong keys: `M` did nothing and the menu opened with `End`, and the other shortcuts were on `Pause`, `Home` and `Page Down`. They are back on their keys:

| Action                 | Key |
| ---------------------- | --- |
| Toggle friend panels   | `H` |
| Toggle compass         | `N` |
| Toggle XYZ coordinates | `J` |
| Open settings menu     | `M` |

Shortcuts saved by an older version are reset to these once. In the menu, `Delete` and `Backspace` clear a shortcut again and `Esc` cancels, instead of being taken as the new key.

## Files

- `papouhud-1.4.2.jar`: the mod, for players (and for Fabric servers).
- `papouhud-paper-1.4.2.jar`: the plugin for Paper 26.3 servers. It doesn't go in `.minecraft/mods`.
