Papou HUD for **Minecraft 26.3**. Players with 1.4.0 or later get this update from the popup at startup.

## New: death skulls with a timer, like status effects

Each death skull now also shows up in the top right of the screen like a harmful status effect, next to the real ones: the skull in its color, with the time its items have left below it ("4:32").

- A skull's 5 minutes only run while someone is near its items (within the server's simulation distance, about 100 blocks on a server set to 6 chunks). While nobody is, the timer is paused: the skull fades and the time turns grey.
- In the last 30 seconds the time turns red.
- It follows the HUD size set in the menu (`M`).

The chat no longer repeats a reminder every minute: it still says where you died, and why a skull went away.

## Files

- `papouhud-1.4.5.jar`: the mod, for players (and for Fabric servers).
- `papouhud-paper-1.4.5.jar`: the plugin for Paper 26.3 servers. It doesn't go in `.minecraft/mods`.
